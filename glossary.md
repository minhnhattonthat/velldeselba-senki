# Glossary - Velldeselba Senki: Tsubasa no Kunshou

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (asked of the user once; options and reasons in docs/decisions.md)
- Honorifics: kept, hyphenated (Name-sama). Name order: Western.
- Romanisation source: official romaji on disc/manual/box first, Hepburn/natural spelling otherwise.
  Official found so far (MobyGames/box): Velldeselba, Misaki, Gidan, Noipask. Nothing else is romanised on the disc.
- Credits: English.
- Register / flavour: mixed by character (D8): each speaker keeps a distinct voice. Sound effects: translated to
  English onomatopoeia (D9).
- Abbreviations: none; full names and terms everywhere, engine changes over shortening.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', …… / ・・・ -> ..., ！？ -> !?, ー (stretched vowel) -> repeat
  the letter or drop it, □ボタン -> Square button (○ Circle, × Cross, △ Triangle).
- Speaker labels: `Name:` then `<R>`, exactly the speaker form in this glossary (rank + name). Player: `<F62>:`.
- `<F62>` = player name, `<F63>` = the player's ship name: copy them, never write "Misaki" for `<F62>`.
- Military address: a superior calls the player "Lieutenant" (少尉); subordinates say "Lieutenant" or "sir".
- Voices: see docs/style-reference.md (from the pilot).
